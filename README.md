# سبحة — تطبيق تسبيح واستغفار بالتمرير

تطبيق ويب بسيط للتسبيح والاستغفار، يعتمد على **التمرير (Scroll)** للعدّ بدلاً من الضغط على الشاشة.

## المزايا
- عدّ عن طريق التمرير بإصبعك للأعلى أو الأسفل (أو عجلة الفأرة على الحاسوب)
- 6 صيغ ذكر جاهزة: سبحان الله، الحمد لله، لا إله إلا الله، الله أكبر، الاستغفار، الصلاة على النبي
- عداد لكل صيغة على حدة + إجمالي عام
- حلقة تقدّم (Progress Ring) توضّح المسافة للهدف (33 أو 100)
- اهتزاز خفيف + نغمة عند إكمال الهدف
- زر تصفير مع تأكيد
- يُحفظ تلقائيًا في الجهاز (localStorage) — لا يضيع عند إغلاق الصفحة
- قابل للتثبيت كتطبيق مستقل (PWA) على الشاشة الرئيسية، ويعمل بدون إنترنت بعد أول فتح

## ⚠️ ملاحظة مهمة
لا يمكن لأي تطبيق ويب (ولا حتى أغلب تطبيقات الأندرويد العادية) أن **يعدّ الحركة أثناء قفل الشاشة**، لأن نظام التشغيل يوقف تنفيذ الصفحة/الحساسات عندها. التطبيق يعمل بشكل كامل والشاشة **مضاءة ومفتوحة**، ويُحفظ العدّ تلقائيًا فور كل تمريرة حتى لو أغلقت المتصفح لاحقًا.

## طريقة الرفع على GitHub Pages
1. أنشئ مستودع (Repository) جديد على GitHub، مثلاً باسم `tasbih-app`.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع (نفس البنية، بدون تغيير الأسماء).
3. من إعدادات المستودع: **Settings → Pages**.
4. اختر **Branch: main** و **Folder: / (root)** ثم احفظ.
5. بعد دقيقة أو دقيقتين، سيظهر رابط مثل:
   `https://USERNAME.github.io/tasbih-app/`
6. افتح الرابط من جوالك → من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية"** ليعمل كتطبيق مستقل.

## بنية الملفات
```
tasbih-app/
├── index.html          (التطبيق كاملاً: HTML + CSS + JS)
├── manifest.json        (إعدادات التثبيت كتطبيق)
├── service-worker.js    (تشغيل بدون إنترنت)
└── icons/
    ├── icon-192.png
    └── icon-512.png
```

## تعديل صيغ الذكر أو الأهداف
كل صيغ الذكر معرّفة في أعلى كود JavaScript داخل `index.html` ضمن المصفوفة `PHRASES`. يمكنك تعديل النص أو الهدف (`target`) لكل صيغة، أو إضافة صيغة جديدة بنفس الشكل:
```js
{ key:"tasbeeh2", label:"سُبْحَانَ اللَّهِ وَبِحَمْدِهِ", short:"سبحان الله وبحمده", target:100 }
```
